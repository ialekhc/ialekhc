
```text id="p7ekbz"
01. Solve the user's problem first.

02. Good UX is part of good engineering.

03. Architecture should reduce complexity,
    not introduce more of it.

04. Build quickly.
    Test.
    Learn.
    Improve.

05. Clean code matters,
    but useful products matter more.
```
